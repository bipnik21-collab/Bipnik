# Bipnik کار کریش ویڈیو مشین

یہ مشین GitHub پر **مفت** چلتی ہے اور ہر بار ایک نئی کار کریش ویڈیو بناتی ہے۔ ویڈیو 1080x1920 کی ہوتی ہے (Shorts، TikTok اور Reels کے لیے)، تقریباً ایک منٹ لمبی، اور اس میں آواز اور Bipnik کا نشان بھی ہوتا ہے۔

## نئی ویڈیو کیسے بنائیں
1. GitHub پر اپنا ریپو کھولیں: `bipnik21-collab/Bipnik`
2. اوپر **Actions** پر کلک کریں۔
3. بائیں طرف **Make Bipnik Crash Video** پر کلک کریں۔
4. دائیں طرف **Run workflow** دبائیں۔ چاہیں تو سیٹنگز بدل لیں (نیچے دیکھیں)، پھر سبز **Run workflow** بٹن دبا دیں۔
5. تقریباً ایک سے ڈیڑھ گھنٹہ انتظار کریں۔ جب سب کے آگے سبز ✓ آ جائے تو اس رن پر کلک کریں۔
6. نیچے **Artifacts** میں **Bipnik-video-...** پر کلک کر کے zip ڈاؤن لوڈ کریں۔ اس میں تین فائلیں ہوں گی:
   - `.mp4` یعنی ویڈیو
   - `_caption.txt` یعنی ٹائٹل، تفصیل اور ہیش ٹیگ
   - `_thumbnail.jpg` یعنی تھمب نیل
7. ویڈیو دیکھیں۔ پسند آئے تو Metricool سے پوسٹ کریں اور ٹائٹل اور تفصیل caption.txt سے کاپی کر لیں۔ **Made for kids = No** رکھیں۔

یہ ویڈیو `videos/crash` فولڈر میں خود بخود محفوظ بھی ہو جاتی ہے۔

## سیٹنگز
| سیٹنگ | مطلب |
|---|---|
| scenario | رکاوٹ: `wall` (دیوار)، `bricks` (اینٹیں)، `bollards` (لوہے کے کھمبے)، `head_on` (آمنے سامنے ٹکر)، `random` (کوئی بھی) |
| runs | کتنی ٹکریں ہوں (آخری ٹکر میں twist ہوتا ہے)۔ 6 رکھیں تو ویڈیو تقریباً ایک منٹ کی بنتی ہے |
| max_speed_kmh | سب سے تیز رفتار، مثلاً 200 |
| quality | `final` اصل ویڈیو کے لیے، `draft` جلدی ٹیسٹ کے لیے (کم کوالٹی) |
| seed | خالی چھوڑیں تو ہر بار نئی ویڈیو بنے گی |

## اگر لال ✗ آ جائے
دوبارہ **Run workflow** کر کے دیکھیں۔ پھر بھی نہ چلے تو لال والے حصے کا اسکرین شاٹ لے کر کسی کوڈنگ ایجنٹ کو دیں اور کہیں:
`The workflow failed. Read the error, fix it, and run it again.`
